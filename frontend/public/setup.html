full setup tutorial
step by step for windows · sharex
windows
linux / mac
1
download and install ShareX
go to the official ShareX GitHub page and download the latest installer. run the .exe and follow the installation wizard.
github.com/ShareX/ShareX/releases/latest
ShareX is free and open source. always download from the official GitHub, not third party sites.
2
import your clinqies config
with ShareX open, click the auto-import button in the quick start section above (you need to be logged in). ShareX will open a dialog asking to confirm the import — click yes.
if auto-import doesn't work, download the .sxcu file manually and import it:
ShareX → Destinations → Custom uploader settings → Import → From file → select the .sxcu file
3
verify the config loaded
go to Destinations → Custom uploader settings. you should see clinqies.xyz in the uploaders list with your API key in the headers section.
the URL field should show {json:url} — if it shows $json:url$ change it to curly braces.
4
set clinqies as your active uploader
in ShareX go to Destinations and change the following:
Image uploader → Custom image uploader
File uploader → Custom file uploader
Text uploader → Custom text uploader
make sure clinqies.xyz is selected in each dropdown in the custom uploader settings.
5
test it
in the custom uploader settings window, click the Test button next to image uploader. you should see a 200 OK response and a URL in the result field.
after a successful test, take a screenshot with Print Screen — the URL is automatically copied to your clipboard and the file appears in your clinqies dashboard.
6
optional — configure hotkeys
go to Hotkey settings to customize your capture shortcuts. recommended setup:
Print Screen → Capture region → upload
Ctrl+Print Screen → Capture fullscreen → upload
Ctrl+Shift+U → Upload file → upload
1
download the shell upload script
log in to your clinqies dashboard, go to Settings → ShareX / API → download shell script. this gives you a pre-configured bash script with your API key.
2
install and configure
move the script to your PATH and make it executable:
chmod +x clinqies-upload.sh
sudo mv clinqies-upload.sh /usr/local/bin/clinqies
3
use with flameshot
configure flameshot to pipe screenshots through the script:
flameshot gui --raw | clinqies /dev/stdin
or upload any file directly:
clinqies /path/to/file.png
requires curl, python3, and xclip (or pbcopy on mac) for clipboard support.
4
bind to a hotkey
add a keyboard shortcut in your desktop environment settings pointing to:
flameshot gui --raw | clinqies /dev/stdin

features
what you can do with clinqies
⇧ file uploads
upload files up to 10GB via ShareX, drag and drop, or ctrl+v to paste images directly. random filenames keep your uploads private.
🔒 password protection
set a password on any upload. viewers see a password gate before accessing the file. set it during upload in the dashboard.
⎯ url shortener
shorten any URL to a clinqies.xyz/s/code link. tracks click counts and supports expiry.
☰ file gallery
select multiple files and create a shareable gallery link. share a set of images or files with one URL.
⏱ file expiry
set files to auto-delete after 1 hour, 24 hours, 7 days, or 30 days. expired files are automatically removed from disk.
⎘ embed codes
after uploading, get instant embed codes in direct URL, HTML img tag, markdown, and bbcode formats.
?
frequently asked questions
ShareX is copying $json:url$ instead of the real URL ►
go to Destinations → Custom uploader settings → click your clinqies.xyz uploader → find the URL field and make sure it says {json:url} with curly braces, not dollar signs. retype it if needed. this is a ShareX version quirk.
the auto-import link doesn't open ShareX ►
ShareX must be installed and the sharex:// URL handler must be registered. try running ShareX once first, then click the link again. if it still doesn't work, download the .sxcu file and import it manually via Destinations → Custom uploader settings → Import → From file.
how do I change my upload quota? ►
quotas are set by the server admin. contact whoever runs your clinqies instance and ask them to adjust your quota in the admin panel.
can I use clinqies without ShareX? ►
yes — log in to the dashboard and upload files directly via drag and drop, the file picker, or ctrl+v to paste images from clipboard. the dashboard gives you full file management.
how do I upload from the command line? ►
download the shell script from Settings → ShareX / API → shell script. it uses curl under the hood and copies the URL to your clipboard automatically. works on linux and mac.
my API key stopped working ►
if you regenerated your API key in Settings, you need to re-download the .sxcu config and re-import it in ShareX. the old key is immediately invalidated when you regenerate.
